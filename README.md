# Zebraland Seiten-Analysator

Dieses Skript hilft Schülern, wichtige Informationen aus dem Buch *Zebraland* für den Deutschunterricht zusammenzufassen.

## Funktionen
- Funktioniert mit Seitenbereichen (z.B. `22-33`)
- Funktioniert mit Einzelseiten (z.B. `6`)
- Funktioniert mit einer Gesamtanalyse (z.B. `alle Seiten`)

## Installation

1. Installiere die Voraussetzungen:
   ```bash
   pip install -r requirements.txt
   ```

2. Hole dir einen kostenlosen API-Schlüssel von [Google AI Studio](https://google.com).
3. Setze den Schlüssel in deinem Terminal:
   - **Windows (CMD):** `set GEMINI_API_KEY=dein_schlüssel_hier`
   - **Mac/Linux:** `export GEMINI_API_KEY="dein_schlüssel_hier"`

4. Starte das Skript:
   ```bash
   python script.py
   ```
